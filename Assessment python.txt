    yield 1
    yield 2
    yield 3

Encapsulation (Explanation)

=>Definition:
Encapsulation is the process of wrapping data (variables) and methods (functions) into a single unit called a class. It also helps protect data by restricting direct access.

sample program
class Student:
    def __init__(self, name, marks):
        self.name = name
        self.__marks = marks    # Private variable

    def display(self):
        print("Name:", self.name)
        print("Marks:", self.__marks)

# Creating object
s1 = Student("Ravi", 95)

# Calling method
s1.display()
